# Sonal Nakhate — Portfolio

## IMPORTANT: Open it the right way
1. Download the ZIP to your computer.
2. In File Explorer, right-click the ZIP and choose **Extract All…**. Finish extraction. Do not open `index.html` from inside the ZIP preview.
3. Open the extracted folder. `index.html` and the `assets` folder must remain side by side.
4. Double-click `index.html`, or open the extracted folder in VS Code and use Live Server.

## Included
- Campus hero background and profile portrait
- Smart-home circuit photo and demo link
- Internship report and certificate PDFs
- Course and Red Hat certificate PDFs

All local image and PDF links use paths relative to `index.html`. Keep the `assets` folder in place. External GitHub, LinkedIn, email and demo links require an internet connection.
